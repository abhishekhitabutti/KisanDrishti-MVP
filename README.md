# KisanDrishti MVP

Crop advisory demo. Enter soil and weather values (N, P, K, temperature, humidity, pH, rainfall) and the app recommends a crop and shows the nutrient gap against that crop's ideal N, P, K profile.

## Run locally

    pip install -r requirements.txt
    streamlit run app.py

## Tech

Python, Streamlit, scikit-learn, NumPy

Live demo: https://kisandrishti-mvp.streamlit.app/
